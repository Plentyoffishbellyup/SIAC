This is the primary repo for SALMON IN A CAN, a fork of [Space Station 14](https://github.com/space-wizards/space-station-14). To prevent people forking RobustToolbox, a "content" pack is loaded by the client and server. This content pack contains everything needed to play the game on one specific server.

If you want to host or create content for SALMON IN A CAN, this is the repo you need. It contains both RobustToolbox and the content pack for development of new content packs.
